# Simulador de Negócio

Sistema de simulação desenvolvido com HTML, CSS e JavaScript puro, onde o usuário gerencia uma empresa mês a mês tomando decisões estratégicas que impactam diretamente o caixa, a receita e as despesas.

O projeto foge do padrão CRUD tradicional e foca em lógica, regras de negócio e controle de estado.

## Funcionalidades
- Simulação mensal de uma empresa
- Controle de caixa
- Cálculo automático de lucro ou prejuízo
- Ações estratégicas:
  - Investir em marketing
  - Contratar funcionário
  - Cortar custos
- Histórico de decisões e resultados
- Sistema de falência quando o caixa chega a zero

---

## Regras de negócio
- O lucro ou prejuízo mensal é calculado pela diferença entre receita e despesas
- Investimentos consomem caixa e alteram receita/despesas
- Decisões têm consequências positivas e negativas
- A empresa entra em falência caso o caixa fique negativo
